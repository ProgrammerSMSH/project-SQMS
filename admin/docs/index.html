System Core

System Mechanism

The SQMS healthcare mechanism ensures that patients are served in the correct order while clinicians maintain full control over their consultation rooms.

Token Generation

When a patient arrives, a unique token is generated for their specific department (e.g., Cardiology, General Medicine). This token is tied to their position in the live queue.

Real-time Sync

The system uses a high-speed websocket mechanism to sync tokens across the Admin Dashboard (Staff) and the TV Display (Patients) instantly.

Patient Workflow

1

Registration

Patient arrives at the reception and receives a printed or digital token number for their consultation.

2

Waiting Area

Patients wait in the lounge, monitoring the TV Display which shows "Now Serving" and "Upcoming" tokens.

3

The Call

When the clinician is ready, the system announces the token number via the TV Display and highlights the assigned room/clinic.

4

Consultation & Exit

After the consultation, the clinician marks the token as "Complete", and the system automatically prepares to call the next patient.
