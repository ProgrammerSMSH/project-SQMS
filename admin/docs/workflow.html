Stage Timeline

System Standby

The internal system is ready. Click the "Simulate" button to begin a journey through the SQMS engine.

Phase 1: API Request

Patient clicks "Join" in the app. A secure JSON request with JWT headers is sent to the Node.js API layer.

Phase 2: Validation

The server performs an auth check and validates the request body. It calculates the next available token number.

Phase 3: Persistence

The server creates a new entry in MongoDB. It atomically increments the queue counter to ensure no duplicate numbers.

Phase 4: Response

Success! The server sends the generated Token ID back to the Patient App for display.

Phase 5: Live Sync

System-wide event broadcast via Socket.io. The Public TV and Staff dashboards receive an instant update.
